# Створення ШІ агентів для малого бізнесу та приватних персон. Інтеграції ШІ у проєкти та підтримка.

## Проблема та спосіб вирішення

Проблема: існують люди що досі не використовували ШІ у житті, бізнес це також сфера де ШІ можна застосувати. Щоб ШІ працював з максимальним ККД треба йому надавати чим більший коннтекст, проте не завжди це можливо у звичайни інтерфейсах котрі використовують більшість користувачів. Щоб подолати бар'єр лімітації контексту, програмування поведікник спілкування та керування форматом відповіді ШІ і створюються ШІ агенти "під ключ".

Спосіб вирішення: хоча агента стврити легко використовуючи сучасні методи, більшість людей досі не розуміють як його інтгерувати у життя. Малий бізнес має безліч процесів котрі неможливо автоматизувати за допомогою простих скриптів або це зробити дуже тяжко, і цього недостатньо щоб наймати окремого працівника, тому ідеально підходить до цього ШІ агент що буде мати доступ до контексту компанії і набір інструкції згідно яких він буде вести себе прогнозовано і раціонально.

## Реалізація 

Щоб забезпечити інтегрування ШІ в будь-який бізнес буде викростовувтися наступні етапи/принципи\тули:

- Вмкористання Github репозиторії протягом періода розбробки за для контролю версій, контролю якості та преревірки коду.
- Docker контейнеризація за для перевіки робочих білдів на пізніх етапів
- Google studio для використання безкоштовних API клюсів для перевірки функцій ШІ, підтримки контексту і тд
- VPS сервери за для розміщення ШІ агнетів для цілодобової  підтрики (залежить від потреб споживача, він купляє його а ми налагоджуємо)
- Всі провайдери ШІ моделей в залжежності від ціни, потреб та інших причин
- C++, Go, Java< Js для для backend частини 
- Html, react, css -для frontend частини 
- SQL, Mysql, Postgra Sql для серверної частини

## Ролі в команді 

CEO: контакт з клієнтами, підпис контрактів від імені організації, укладання договорів, вся бюрокртація, керування підписакми та витратами 
DEVELOPERS: розробка full stack частини, сервернох логіки, підтрика наявних проектів
SMM: реклама в соцмережах, знімання контекнту, тестування агентів в альфа стадії 
MARKETOLOG: аналіз ринку конкурентів, пошук нових ідей, складання рекламної кампанії, тестих прес-реріз версій
TEAM LEAD: орнганізація процесу, DevOps, перевірка PRЖ, інтерв'ю з клієнтом

## Витрати 

ЩОб теоретично запустити стартап треба витратити мінімальні кошти на :
1) Підписки для коду такі як Codex або Claude (~200$)
2) Курівля VPS сервера для тестування версій (~50$)
3) Реклама та пошук клієнтів (~200$)
4) Незаплановані витрати та відпочинок (~100$)


## ЩО можемо зробити 

Ідея створення ШІ агентів недостатньо для створення комерційного продукту, тому компанія буде покладатися на більш комплексну реалізацію, ми не тільки будемо створювати ШІ агента, але також логіку підтримки, зручну комунікацію, та детальний розбір потреб клієнта та знаходження оптимального рішення. 
    Кожен агнет буде створення саме для окремого кейсу, і наприклад клієнта вирішує:
    - що має робити агент
    - що має знати агент
    - як себе має поводити
    - з ким він буде спілкуватся (клієнти продукту або працівники)
