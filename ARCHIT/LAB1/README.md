# Лабораторна робота №1: Методи переведення чисел з однієї системи числення в іншу

**Дисципліна:** Архітектура комп'ютера  
**Тема:** Методи переведення чисел з однієї системи числення в іншу  
**Завдання №2:** Розробити програму, яка буде переводити введене користувачем ціле або дробове число з двійкової системи числення у десяткову систему числення з виведенням результату на екран.

---

## 📌 Опис проекту

Програма реалізована мовою **Python** з використанням бібліотеки графічного інтерфейсу **Tkinter / ttk**. Додаток не вимагає встановлення зовнішніх залежностей і працює на будь-якому ПК зі стандартним Python 3.

### Основні можливості програми:
1. **Підтримка цілих та дробових чисел**:
   - Розділювач цілої та дробової частини може бути як крапкою `.`, так і комою `,` (наприклад, `1101.101` або `1101,101`).
2. **Підтримка знаку**:
   - Підтримка додатних (`+`) та від'ємних (`-`) чисел.
3. **Надійна валідація введення**:
   - Перевірка на сторонні символи (дозволені лише `0`, `1`, знак та роздільник).
   - Інформативні повідомлення у разі помилки.
4. **Висока точність обчислень**:
   - Використання модуля `decimal.Decimal` запобігає похибкам двійкової арифметики IEEE-754 з плаваючою крапкою.
5. **Повний математичний розклад**:
   - Відображення аналітичної формули розкладу за поліномом степенів двійки $\sum (b_i \cdot 2^i)$.
   - Покрокова таблиця внеску кожного двійкового розряду.
6. **Швидкі пресети та копіювання**:
   - Кнопки для швидкого завантаження прикладів (зокрема з методичних вказівок).
   - Копіювання отриманого результату в буфер обміну в один клік.

## 🧮 Математична модель

Переведення числа з двійкової позиційної системи числення в десяткову базується на представленні числа у вигляді степеневого полінома:

$$N_{10} = \sum_{i=0}^{n-1} a_i \cdot 2^i + \sum_{j=1}^{m} b_j \cdot 2^{-j}$$

де:
- $a_i \in \{0, 1\}$ — розряди цілої частини ($i = 0, 1, \dots, n-1$);
- $b_j \in \{0, 1\}$ — розряди дробової частини ($j = 1, 2, \dots, m$);
- $2^i$ та $2^{-j}$ — вага відповідного двійкового розряду.

### Приклад (з методичних вказівок):
$$110100101_2 = 1\cdot 2^8 + 1\cdot 2^7 + 0\cdot 2^6 + 1\cdot 2^5 + 0\cdot 2^4 + 0\cdot 2^3 + 1\cdot 2^2 + 0\cdot 2^1 + 1\cdot 2^0 = 421_{10}$$

### Дробовий приклад:
$$1011.1101_2 = (1\cdot 2^3 + 0\cdot 2^2 + 1\cdot 2^1 + 1\cdot 2^0) + (1\cdot 2^{-1} + 1\cdot 2^{-2} + 0\cdot 2^{-3} + 1\cdot 2^{-4})$$
$$= (8 + 0 + 2 + 1) + (0.5 + 0.25 + 0 + 0.0625) = 11.8125_{10}$$

## 📁 Структура файлів

- **`main.py`** — головний модуль десктопного графічного інтерфейсу (GUI) на Tkinter.
- **`converter.py`** — ядро математичної логіки, валідації та покрокової декомпозиції чисел.
