# Лабораторна робота №5 — Варіант 1.12

**Хеш-функція:** 1.12 — SHABAL (512 біт).
**Застосування:** 3б) — обчислення контрольної суми файлу, яка дописується в кінець цього файлу.
**Власна хеш-функція:** метод множення (варіант 12 парний).

## Запуск

```bash
g++ -O2 -std=c++20 main.cpp -o main.exe
.\main.exe
```

Після запуску програма запитує ім'я файлу (Enter — `getfile.pdf`), далі — меню:

| Пункт | Дія |
|---|---|
| 1 | Обчислити контрольну суму файлу (SHABAL-512 + власна функція) |
| 2 | Дописати контрольну суму 64 байти в кінець файлу |
| 3 | Перевірити дописану суму |
| 4 | Порівняння хеш-функцій (кількість колізій) |
| 0 | Вихід |

## Перевірка правильності SHABAL-512

Реалізація **перевірена двома незалежними способами** — це важливо, бо Shabal
є результатом конкурсу SHA-3 і має точну специфікацію:

1. **Звірка з еталонною реалізацією** `sph_shabal.c` (Projet RNRT SAPHIR) на
   **171 тестовому векторі**: довжини повідомлень 0…130 байт поспільно + 40
   випадкових довжин до 5000 байт. Результат: **0 розбіжностей**.
2. **Selftest при кожному запуску** — програма обчислює `Shabal-512("")` і
   порівнює з еталонним значенням:

```
ff5d2dfc f6b7705d fcc2f8b1 fef9c1c8 42e53499 0ceded57 a239b5f2 cc190aef
8d4fa8ff e435a19f f5093cbd 27a9f390 ac03d6eb 9e72eb29 f09a2a6f c68dad31
```

## Результати експерименту з колізіями (пункт 5)

Таблиця на 2¹³ = 8192 комірок, заповнення 4915 комірок (59 %), потім вставляється
700 нових ключів. Очікувано колізій: 700 × 4915/8192 ≈ **419**.

| Діапазон ключів | SHABAL-512 | Множення | Дішення |
|---|---:|---:|---:|
| 0..10⁴ | 515 (735 ‰) | 534 (762 ‰) | 413 (590 ‰) |
| 0..10⁶ | 336 (480 ‰) | 325 (464 ‰) | 336 (480 ‰) |
| 0..10⁹ | 334 (477 ‰) | 318 (454 ‰) | 330 (471 ‰) |

**Висновок:** на кількість колізій впливає насамперед діапазон вхідних даних
відносно розміру таблиці, а не вибір хеш-функції. Для вузького діапазону
0..10⁴ усі три функції дали в ~1,5 раза більше колізій, ніж для широких діапазонів.
