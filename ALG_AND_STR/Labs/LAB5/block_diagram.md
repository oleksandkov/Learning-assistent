**Задача:** Програмна реалізація хеш-функції SHABAL-256 (варіант 1.12), методу множення (парний варіант 12), верифікація цілісності файлів (завдання 3б) та експериментальний аналіз колізій.

## 2. Специфікація діаграми за стандартом UML (PlantUML)

```plantuml
@startuml
title Діаграма діяльності (UML Activity Diagram) - Лабораторна робота №5, Варіант 1.12

start
:Ініціалізація та виклик run_tests() [assert];
:Вибір операції у головному меню;

partition "Підпрограма SHABAL-256" {
  :Доповнення даних (Padding 0x80 та нулі до 64 байтів);
  :Розбиття блоку на 16 слів M[0..15];
  :Додавання слів до регістра B та накладання лічильника W;
  :Криптографічна перестановка perm(M) (48 раундів);
  :Фіналізація (3 цикли swap(B, C), XOR W та perm(M));
  :Вибірка слів B[8..15] у 256-бітний дайджест;
}

partition "Хеш-таблиця з методом ланцюгів" {
  :Обчислення індексу комірки idx = hash(key) % m;
  if (Ключ знайдено в ланцюгу buckets[idx]?) then (так)
    :Оновлення існуючого значення;
  else (ні)
    :Додавання нового елемента в кінець ланцюга;
    :Інкремент кількості елементів count;
  endif
  :Оновлення коефіцієнта наповнення α = n/m;
}

partition "Контроль цілісності файлу (3б)" {
  if (Операція з файлом?) then (дописування)
    :Розрахунок дайджесту SHABAL-256;
    :Дописування маркера підпису в кінець файлу;
  else (перевірка)
    :Відокремлення контрольної суми від тіла файлу;
    :Повторний розрахунок хешу та порівняння;
    if (Хеші збігаються?) then (так)
      :Вивід статусу INTEGRITY VERIFIED (OK);
    else (ні)
      :Повідомлення про порушення цілісності;
    endif
  endif
}

:Вивід результатів та вихід з програми;
stop
@enduml
```

## 3. Таблиця відповідності елементів стандарту UML

| Елемент стандарту UML | Позначення на блок-схемі | Призначення в алгоритмі |
| :--- | :--- | :--- |
| **Initial Node** | Округлий блок (зелений) | Початок роботи функції `main()` |
| **Action State** | Прямокутник із заокругленими кутами | Операція обробки даних (доповнення, зсув, вставка) |
| **Decision Node** | Ромб (помаранчевий) | Перевірка умов (наявність ключа, валідація дайджесту) |
| **Merge Node** | Зведення ліній зі стрілками | Об'єднання результатів розгалуження |
| **Partition (Swimlane)** | Пунктирний контур із заголовком | Групування логіки підпрограм (SHABAL, таблиця, файл) |
| **Activity Final Node** | Округлий подвійний блок (червоний) | Успішне завершення роботи програми |
