# Лабораторна робота №4: Алгоритми сортування (Варіант 12)

## 1. Загальний опис та мета роботи

**Мета:** Дослідження та порівняльний аналіз двох алгоритмів сортування згідно з варіантом 12:
- **Алгоритм №3:** Сортування вставкою (*Insertion sort*);
- **Алгоритм №8:** Сортування за допомогою двійкового дерева пошуку (*Tree sort*).

Програма здійснює теоретичний аналіз складності та експериментальні вимірювання часу виконання на тестових масивах розмірністю від $1\,000$ до $100\,000$ елементів для трьох характерних розподілів даних:
1. **Випадкові дані (Random)** — середній випадок;
2. **Вже відсортовані дані (Sorted)** — найкращий випадок для вставки;
3. **Зворотньо відсортовані дані (Reverse sorted)** — найгірший випадок для вставки.

---

## 2. Теоретичний аналіз алгоритмів

| Характеристика | Сортування вставкою (Insertion sort) | Сортування двійковим деревом (Tree sort) |
| :--- | :--- | :--- |
| **Найкращий час** | $O(N)$ — масив уже відсортований | $O(N \log N)$ — збалансоване дерево |
| **Середній час** | $O(N^2)$ — випадковий порядок | $O(N \log N)$ — випадковий порядок |
| **Найгірший час** | $O(N^2)$ — зворотний порядок | $O(N^2)$ — виродження у зв'язаний список |
| **Просторова складність** | $O(1)$ — працює на місці (*in-place*) | $O(N)$ — додаткова пам'ять для вузлів дерева |
| **Стійкість (Stability)** | Стійкий (Stable) | Стійкий при збереженні порядку однакових ключів |

---

## 3. Опис реалізації

### 3.1. Сортування вставкою (`insertion_sort`)
Алгоритм розглядає масив як дві частини: відсортовану (зліва) та невідсортовану (справа). На кожному кроці $i$ вибирається поточний елемент `key = a[i]`, і серед елементів $j = i-1 \dots 0$ відбувається пошук позиції для вставки. Усі елементи, більші за `key`, зсуваються на одну позицію вправо:
```cpp
void insertion_sort(std::vector<int>& a) {
    int n = static_cast<int>(a.size());
    for (int i = 1; i < n; ++i) {
        int key = a[i];
        int j = i - 1;
        while (j >= 0 && a[j] > key) {
            a[j + 1] = a[j];
            --j;
        }
        a[j + 1] = key;
    }
}
```

### 3.2. Сортування двійковим деревом (`tree_sort`)
1. **Вузол дерева (`TreeNode`)**:
   Зберігає значення `val`, лічильник дублікатів `count` (дозволяє оптимізувати пам'ять при однакових значеннях) та покажчики на ліве й праве піддерево (`left`, `right`).
2. **Вставка (`insert_bst`)**:
   Ітеративний спуск по двійковому дереву пошуку (BST). Менші елементи прямують у ліве піддерево, більші — у праве.
3. **Симетричний обхід (`inorder`)**:
   Рекурсивно обходить дерево в порядку `Left -> Root -> Right`, записуючи елементи назад у масив у впорядкованому вигляді.
4. **Вивільнення пам'яті (`free_tree`)**:
   Рекурсивне звільнення виділеної динамічної пам'яті вузлів (Post-order).
