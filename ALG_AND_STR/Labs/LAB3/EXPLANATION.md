## 1. Постановка задачі

Відповідно до завдання варіанту 12:
- **Структура даних:** двозв'язний список з розгалуженнями.
- **Тип елементів:** `Ім'я | Послідовність чисел`.
- **Правило організації:** послідовність чисел може містити від $1$ до $N$ елементів. Якщо довжина послідовності перевищує поріг $K$ ($K < N$), надлишкові числа виносяться в окрему **гілку** (підсписок).
- **Базові константи:**
  - $K = 3$ — гранична кількість чисел, які зберігаються безпосередньо в основному вузлі.
  - $N = 10$ — максимальна допустима довжина числової послідовності для одного запису.

### Необхідні операції:
1. **Додавання елементів у список** (із формуванням гілки за умови довжини $> K$).
2. **Пошук і роздрукування елемента в списку** (за іменем, з відображенням як основного блоку, так і його розгалуження).
3. **Видалення елемента зі списку** (із коректним вивільненням пам'яті основного вузла та всіх елементів його гілки).
4. **Підрахунок елементів у списку** (швидке отримання поточної кількості вузлів).
5. **Роздрукування всього списку** (послідовне виведення кожного запису з індикацією наявності чи відсутності гілки).

## 2. Організація структур даних у пам'яті

Для розв'язання задачі реалізовано дворівневу зв'язну топологію:
1. **Основна магістраль** — лінійний двозв'язний список (вузли зв'язані вперед через `next` та назад через `prev`).
2. **Гілки розгалужень** — динамічний однозв'язний список вузлів `BranchNode`, на початок якого вказує покажчик `branch` основного вузла (якщо чисел $> K$).

### Графічна схема пам'яті:

```text
  nullptr
     ^
     | (prev)
+-----------------------+           +-----------------------+
|        Node 1         |  (next)   |        Node 2         |
| Name: "Запис_1"       | --------> | Name: "Запис_2"       | --------> ... -> nullptr
| main_nums: [5, 12]    | <-------- | main_nums: [10,20,30] |
| branch: nullptr       |  (prev)   | branch: * ------------+
+-----------------------+           +-----------------------+
                                                |
                                                v (down)
                                       +-----------------+
                                       | BranchNode (40) |
                                       | next: * --------+
                                       +-----------------+
                                                |
                                                v
                                       +-----------------+
                                       | BranchNode (50) |
                                       | next: * --------+
                                       +-----------------+
                                                |
                                                v
                                       +-----------------+
                                       | BranchNode (60) |
                                       | next: nullptr   |
                                       +-----------------+
```

### Структури у коді [`main.cpp`](file:///C:/Github/Learning-assistent/ALG_AND_STR/Labs/LAB3/main.cpp):

```cpp
// 1. Вузол гілки (однозв'язний список для надлишкових чисел)
struct BranchNode {
    int value;
    BranchNode* next = nullptr;
};

// 2. Вузол основного двозв'язного списку
struct Node {
    std::string name;             // Ім'я / ключ елемента
    int main_count = 0;           // Фактична кількість чисел в основному вузлі (<= K)
    int main_nums[K]{};           // Статичний масив фіксованого розміру K для основних чисел
    BranchNode* branch = nullptr; // Покажчик на початок гілки розгалуження (числа > K)
    Node* prev = nullptr;         // Покажчик на попередній елемент списку
    Node* next = nullptr;         // Покажчик на наступний елемент списку
};

// 3. Клас-обгортка двозв'язного списку з розгалуженнями
struct DoublyBranchedList {
    Node* head = nullptr;         // Покажчик на перший елемент списку
    Node* tail = nullptr;         // Покажчик на останній елемент списку
    int count = 0;                // Кількість елементів у списку
    ...
};
```

## 3. Детальний розбір операцій

### 3.1. Додавання елемента (`push_back`)

При додаванні послідовності `nums` розміром `total`:
1. Розмір обмежується константою $N$: `if (total > N) total = N;`.
2. Виділяється новий динамічний об'єкт `Node` через оператор `new`.
3. Перші $\min(total, K)$ чисел копіюються безпосередньо у масив `main_nums` поточного вузла.
4. Якщо $total > K$:
   - Для чисел від індексу $K$ до $total - 1$ створюються динамічні вузли `BranchNode`.
   - Зв'язування гілки реалізовано ефективно через непрямий покажчик `BranchNode** b_tail`, що усуває необхідність щоразу шукати кінець гілки:
     ```cpp
     BranchNode** b_tail = &node->branch;
     for (int i = K; i < total; ++i) {
         *b_tail = new BranchNode{nums[i], nullptr};
         b_tail = &((*b_tail)->next);
     }
     ```
5. Вузол додається в кінець двозв'язного списку за час $O(1)$:
   - Якщо список був порожній: `head = tail = node;`.
   - Якщо не порожній: `tail->next = node; node->prev = tail; tail = node;`.
6. Лічильник елементів інкрементується: `++count;`.

### 3.2. Пошук і роздрукування (`find` + `print_node`)

- Функція `find(const std::string& name)` виконує лінійний прохід від `head` за допомогою покажчика `curr = curr->next`. Якщо `curr->name == name`, повертається адреса вузла `curr`, інакше `nullptr`.
- Функція `print_node(const Node* node)` виводить:
  - Ім'я вузла;
  - Вміст основного масиву `main_nums` у форматі `[x, y, z]`;
  - Вміст гілки: якщо `branch == nullptr`, друкується `"відсутня"`, інакше здійснюється ітерація `for (BranchNode* b = node->branch; b; b = b->next)` із виведенням значень через стрілку `->`.

### 3.3. Видалення елемента (`remove`)

Видалення елемента за іменем виконується в чотири кроки:
1. **Пошук вузла:** `Node* target = find(name);`. Якщо не знайдено — повертається `false`.
2. **Переприв'язка сусідніх покажчиків у двозв'язному списку:**
   - Для лівого сусіда:
     ```cpp
     if (target->prev) target->prev->next = target->next;
     else head = target->next; // Видаляли голову списку
     ```
   - Для правого сусіда:
     ```cpp
     if (target->next) target->next->prev = target->prev;
     else tail = target->prev; // Видаляли хвіст списку
     ```
3. **Вивільнення пам'яті гілки:**
   - Допоміжна функція `free_branch(target->branch)` проходить по всіх вузлах `BranchNode` та викликає для кожного `delete`.
4. **Вивільнення пам'яті вузла та декремент:**
   - `delete target; --count; return true;`.

### 3.4. Підрахунок елементів (`size`)

- Завдяки полю `int count`, що підтримується при кожній вставці та видаленні, операція повернення розміру виконується за **константний час $O(1)$** без необхідності повторного обходу списку.

### 3.5. Очищення пам'яті та деструктор (`clear` / `~DoublyBranchedList`)

Для запобігання витокам пам'яті (memory leaks) реалізовано деструктор за ідіомою **RAII**:
- Метод `clear()` послідовно проходить по кожному вузлу основного списку:
  1. Зберігає покажчик на наступний вузол: `Node* nxt = curr->next;`.
  2. Вивільняє всю його гілку розгалуження: `free_branch(curr->branch);`.
  3. Знищує сам вузол `delete curr;`.
  4. Переходить до наступного: `curr = nxt;`.
- Поля `head` і `tail` обнуляються (`nullptr`), а лічильник `count` стає рівним 0.

## 4. Складність алгоритмів

| Операція | Часова складність | Просторова складність | Примітка |
| :--- | :---: | :---: | :--- |
| Додавання у хвіст (`push_back`) | $O(1)$ | $O(\min(m, N))$ | $m$ — довжина вхідної послідовності |
| Пошук за іменем (`find`) | $O(n)$ | $O(1)$ | $n$ — кількість елементів списку |
| Видалення за іменем (`remove`) | $O(n)$ | $O(1)$ | $O(n)$ на пошук, $O(1)$ на переприв'язку та $O(L)$ на гілку |
| Підрахунок кількості (`size`) | $O(1)$ | $O(1)$ | Значення зберігається в окремому полі `count` |
| Роздрукування списку (`print_all`) | $O(\sum m_i)$ | $O(1)$ | Лінійний прохід по всіх вузлах і гілках |
