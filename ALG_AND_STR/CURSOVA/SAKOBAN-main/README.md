# SOKOBAN — Інструкція із запуску (CLI та Web)

Проєкт містить дві версії гри, що працюють на спільному ядрі C++20:
1. **CLI-версія** — консольний застосунок із термінальним інтерфейсом, генератором рівнів та бенчмарками.
2. **Web-версія** — браузерний застосунок на Next.js / React з інтерактивним інтерфейсом та навчальними темами.

---

## 1. Системні вимоги

- **Для CLI**: Компілятор C++20 (GCC 11+ / MinGW-w64 / MSYS2).
- **Для Web**: Node.js 18.17+ (LTS) та встановлений компілятор C++20 (g++ у PATH або MSYS2 для нативного мосту).

---

## 2. Запуск CLI-версії (Консоль)

### Швидкий запуск (готовий бінарник)
У корені репозиторію вже знаходиться зібраний виконуваний файл:

```powershell
# Головне інтерактивне меню (вибір рівня, гра, AI solver, бенчмарки)
.\sokoban_cli.exe

# Прямий запуск проходження рівня
.\sokoban_cli.exe play levels/01_simple.xsb

# Розв'язання рівня алгоритмом A* (мінімізація штовхань)
.\sokoban_cli.exe solve levels/02_microban.xsb --algorithm astar --metric pushes

# Порівняння алгоритмів (BFS vs A* Moves vs A* Pushes vs IDA* vs Greedy)
.\sokoban_cli.exe compare levels/02_microban.xsb
```

### Збирання з вихідного коду (за потреби)

- **Варіант А (швидкий скрипт Windows)**:
  ```powershell
  .\build.bat
  ```

- **Варіант Б (через CMake)**:
  ```powershell
  cmake -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
  cmake --build build
  .\build\sokoban_cli.exe
  ```

### Керування у CLI:
- **WASD** або **Стрілки** — переміщення гравця / штовхання ящиків
- **U** — скасувати хід (Undo)
- **Y** — повторити скасований хід (Redo)
- **R** — перезапустити рівень (Restart)
- **H** — отримати підказку ШІ (перший хід A* з поточної позиції)
- **B** / **M** / **P** (або **1**) — розв'язати одним алгоритмом: BFS / A* ходи / A* штовхання
- **G** — розв'язати через AI (провайдер авто за ключем: Groq / Google; **K** — ввести ключ)
- **T** — порівняти всі алгоритми з поточної позиції (таблиця статистики, як у web) і обрати рішення для виконання
- **Пробіл** — пауза / продовження відтворення розв'язку
- **N** — один крок розв'язку (AI step)
- **Q** або **Esc** — вихід

### AI API-ключ у CLI (як сторінка `/ai` у web):
- У грі натисни **K** і встав ключ: **Groq** ([console.groq.com](https://console.groq.com), безкоштовний free tier, змінна `GROQ_API_KEY`)
  або **Google AI Studio** ([aistudio.google.com](https://aistudio.google.com/app/apikey), `GEMINI_API_KEY`).
  Клієнт сам аналізує ключ (`AIza...`/`AQ.` → Google, інше → Groq) і обирає провайдера.
  Ключ зберігається локально у `~/.sokoban_ai_key` (старий `~/.sokoban_gemini_key` теж читається).
- Groq: OpenAI-сумісний `chat/completions`, швидкі безкоштовні моделі —
  `openai/gpt-oss-120b` (за замовчуванням, reasoning), `llama-3.3-70b-versatile`,
  `moonshotai/kimi-k2-instruct`, `qwen/qwen3-32b`, `openai/gpt-oss-20b`, `llama-3.1-8b-instant`.
  Вибір — пункт 2 у «Налаштувати ШІ» або змінна `GROQ_MODEL`. Free tier має денні ліміти.
  Google: той самий запит, що й web (`generateContent` + codeExecution, `gemini-3.8-flash`).
- Кожен повернутий маршрут перевіряється ядром (ReplayValidator) перед застосуванням.
- Порівняння клавішею **T** включає рядок **AI** (без ключа — підказка `Немає ключа [K]`);
  на вузькому терміналі таблиця автоматично стає компактною, щоб рядки не переносились.
- При 429/5xx CLI автоматично повторює запит до 3 разів з паузами 2с/4с і показує
  кількість спроб. Помилка 503 — брак потужностей провайдера, не помилка рівня.
- Консоль: `sokoban_cli solve <рівень> --algorithm ai` (авто), `gemini` / `groq` (примусово).

### Кодування символів у Windows (UTF-8)

Програма автоматично налаштовує консоль на кодову сторінку UTF-8 (`CP_UTF8 / 65001`). 

Якщо у вашому терміналі (наприклад, класичному `cmd.exe` чи застарілому PowerShell 5.1) українські літери відображаються некоректно (`╨У╨Ю╨Ы...`), перемкніть кодову сторінку перед запуском:

- **У PowerShell**:
  ```powershell
  chcp 65001
  # або
  [Console]::OutputEncoding = [System.Text.Encoding]::UTF8
  ```
- **У CMD**:
  ```cmd
  chcp 65001
  ```
- **Рекомендація**: використовувати сучасний **Windows Terminal** зі шрифтами *Cascadia Code* або *Consolas*.

## 3. Запуск Web-версії (Браузер)

Web-версія реалізована на базі Next.js і викликає спільне C++20 ядро через нативний міст.

### Режим розробки (Development)

1. Перейдіть у каталог `web` та встановіть npm-пакети:
   ```powershell
   cd web
   npm install
   ```

2. Запустіть dev-сервер (C++ міст скомпілюється автоматично):
   ```powershell
   npm run dev
   ```

3. Відкрийте браузер за адресою:
   **[http://localhost:3000](http://localhost:3000)**

### Збирання та запуск у Production

```powershell
cd web
npm run build
npm run start
```

### Можливості веб-інтерфейсу:
- Вибір рівнів різної складності (`/levels`);
- Ручна гра з підтримкою клавіатури (WASD / Стрілки, U, Y, R, H) та екранних кнопок;
- Покрокове відтворення знайдених рішень ШІ (BFS, A* Moves, A* Pushes);
- Інтерактивні навчальні візуалізації алгоритмів (`/about`).
