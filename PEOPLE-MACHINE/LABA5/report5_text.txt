КАФЕДРА ПРОГРАМНОГО ЗАБЕЗПЕЧЕННЯ

Звіт про виконання лабораторної роботи № 5




Виконав (ла): ст. 1 курсу, групи 2ПІ-25Б 
Коваль Олександр
Перевірив: викладач Ткаченко О. М.








Мета: знайомство з мовними інтерфейсами та Microsoft SAPI.

Тема:  Розробка інтерфейсу та програмна реалізація розпізнавання голосу для лабораторної робити 4. Інтеграція ШІ до виконання завдань через голосові команди

Завдання: реалізація або інтеграція програми із розпізнаванням голосу шляхом використання API SPEECH-TO-TEXT. Інтеграція ШІ агенту та API для розпізнавання голосу до веб застосунку лабораторної роботи 4.

КОД ПРОГРАМИ

Висновок: У ході виконання роботи було розроблено та вдосконалено систему керування розкладом занять із голосовим та текстовим введенням.. Забезпечено стабільну обробку команд додавання та редагування, а також узгоджене відображення даних у базі й інтерфейсі. Отримані результати підтверджують працездатність системи та відповідність вимогам завдання. Було використано API для сервісу розпізнавання голосу Assembly та API для керування командами завдяки ШІ агенту від компанії Google gemini-2.5-flash.
