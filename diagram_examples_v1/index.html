Каталог V1: Академічний ГОСТ 19.701-90 та UML

Версія V1 враховує всі ваші вимоги: прозорий/білий фон, повна відсутність заголовків на зображеннях, суто український текст та строгий чорно-білий академічний стиль.

Параметри стандарту V1:
  • Фон: прозорий (transparent) / блоки залиті чистим білим кольором (#ffffff) для уникнення накладання ліній.
  • Без заголовків на самому малюнку: схема починається одразу з початкового вузла, без декоративних написів чи рамок.
  • Мова: виключно українська термінологія ("Початок", "Кінець", "Введення", "Виведення", "Так", "Ні").
  • Геометрія ГОСТ 19.701-90: злами ліній строго 90°, паралелограми для вводу/виводу, ромби умов, подвійні лінії для підпрограм, шестикутники для циклу For.
