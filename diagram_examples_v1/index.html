Академічні схеми — ГОСТ 19.701-90 та UML 2.5

Монохромний стиль еталонних зображень: Times New Roman, контури 1.5 px, біла заливка блоків, прозорий фон, злами тільки під 90°. Усі схеми генеруються скриптами, тож будь-яку програму можна перенести в цей стиль копіюванням прикладу.

Тип
Підкладка
Масштаб

Як зробити схему для своєї програми

from scripts.gost import Chart

c = Chart()                      # wrap_w=470 — стандартна ширина блоків
s = c.start()
i = c.io("Введення: n, arr", below=s)
a = c.process("сума = 0", below=i)
d = c.decision("i < n", below=a)
b = c.process("сума += arr[i]", below=d)
k = c.process("i += 1", below=b)
o = c.io("Виведення: сума", below=d, dy=150)
e = c.end(below=o)

c.drop(a, d)
c.drop(d, b)                    # вертикаль магістралі, без наконечника
c.tag(b, "Так", "top", dx=9, dy=-16)
c.loop(k, d, side="left")       # зворотний зв'язок циклу
c.branch(d, o, "right", "Ні")   # вихід з циклу
c.drop(o, e)

open("out.svg", "w", encoding="utf-8").write(c.render())
